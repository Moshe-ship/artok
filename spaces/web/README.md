# artok عرتوك — Arabic Token Tax Calculator

See how much more Arabic costs across 18 LLM tokenizers. Arabic text uses
2–5× more tokens than equivalent English, so the same request costs more in
Arabic. This calculator shows the gap per tokenizer.

- Code: https://github.com/Moshe-ship/artok
- Part of the [Mizan](https://github.com/Moshe-ship/mizan) stack — the pain
  proof / top of funnel for Arabic-first agent reliability.
